## 当前主要缺口

1. 在现有关键词证据链上补齐检索质量评测、来源治理；向量按用户要求暂缓。
2. 设计并实现长期记忆的提取、确认、存储、召回、删除和 ACL。
3. 接入真实工单系统，形成诊断到建单/升级的闭环。
4. 补齐知识生命周期安全、并发和浏览器验收测试。
5. Run attempt/租约/隔离、输入边界、实时授权、预算/证据上下文和租户轮转已有实现；继续补写动作生命周期。

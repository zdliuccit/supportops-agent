# 模块实现状态

| 模块 | 状态 | 当前说明 |
| --- | --- | --- |
| 身份与租户 | 已实现 | JWT、角色、用户状态和租户隔离 |
| Agent 控制面 | 已实现 | 草稿、版本、发布、激活、回滚、停用 |
| 模型端点 | 已实现 | 端点版本、凭据 revision、能力测试和测试历史 |
| Agent 运行时 | 已实现 | `create_agent`、工具过滤、结构化输出和运行限制 |
| 会话短期记忆 | 已实现 | 产品消息与 PostgreSQL checkpoint |
| 长期记忆 | 未实现 | 只有配置预留，没有独立读写和召回链路 |
| 知识生命周期 | 基础已实现 | 来源、文档版本、ACL、审核、发布快照 |
| 知识检索与引用 | 未实现 | 尚未接入 Agent 推理主流程 |
| 工具目录 | 基础已实现 | `current_identity_summary` 可用；工单查询未连接真实系统 |
| Worker 与事件流 | 已实现 | Redis、状态机、恢复扫描、SSE |
| 可观测性 | 基础已实现 | Trace、错误、Token、成本、延迟、Dashboard |
| 人工审批 | 未实现 | 属于后续 P1 能力 |

## 当前主要缺口

1. 将知识有效快照接入受权限控制的检索、引用和答案生成。
2. 设计并实现长期记忆的提取、确认、存储、召回、删除和 ACL。
3. 接入真实工单系统，形成诊断到建单/升级的闭环。
4. 补齐知识生命周期安全、并发和浏览器验收测试。

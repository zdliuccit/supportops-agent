## Requirements
### Requirement: P0 发布范围
P0 SHALL 提供多轮会话、可追溯知识问答、引用、4 至 6 个受控只读工具、429 业务诊断、自动建单、基础 Agent 工作流、SSE 事件、会话和 Run 持久化、基础 Trace 以及离线评测。P0 SHALL 以单产品域、单 Agent 和 Mock 业务系统为默认边界。

#### Scenario: P0 范围验收
- **WHEN** 团队申请将 P0 标记为完成
- **THEN** 知识问答、429 业务诊断、证据不足自动建单和依赖失败降级四条主路径均通过端到端验收

### Requirement: P1 发布范围
P1 SHALL 在 P0 基础上增加人工审批、客服接管、完整 RBAC 与 ABAC、租户隔离、日志脱敏、工单全流程、知识版本管理、离线回归评测、成本监控和失败降级，并至少通过一个 R4 操作验证完整审批、幂等执行和复核闭环。

#### Scenario: P1 高风险闭环验收
- **WHEN** 团队申请将 P1 标记为完成
- **THEN** 一个 R4 操作已覆盖申请、参数冻结、非本人审批、拒绝、修改后重审、过期、一次性执行、超时恢复和执行后复核场景

### Requirement: P2 启动条件
P2 能力 SHALL 基于 P1 试运行取得的真实质量、成本、容量和组织瓶颈立项。多渠道、模型路由、在线评测、自动知识更新、高可用和领域子 Agent 不得仅因存在于远期路线图而进入承诺范围。

#### Scenario: 提议拆分多 Agent
- **WHEN** 团队计划按领域拆分子 Agent
- **THEN** 提案提供单 Agent 的质量、延迟、成本或职责边界瓶颈证据，并定义拆分收益和回归标准

### Requirement: 功能验收门槛
发布候选 SHALL 验证其范围内的正常路径、边界条件、错误处理和恢复路径。知识答案 SHALL 有有效引用，工具输入输出 SHALL 通过 Schema 校验，人工升级 SHALL 携带完整上下文，且模型不得伪造知识、工具或执行结果。

#### Scenario: 引用缺失
- **WHEN** 发布评测发现有依据的知识回答无法提供有效引用
- **THEN** 发布候选不得通过功能门禁

### Requirement: 安全验收门槛
P1 发布候选 MUST 通过跨租户拒绝、角色越权拒绝、R4 无凭证拒绝、审批参数篡改拒绝、敏感字段防泄露和 Prompt Injection 红队测试。任何高风险审批绕过或严重敏感数据泄露 SHALL 阻断发布。

#### Scenario: R4 审批绕过
- **WHEN** 任一测试路径能够在没有有效审批凭证时执行 R4 操作
- **THEN** 发布立即被阻断，且不得通过降低风险等级或关闭校验解决

### Requirement: 质量指标基线
试运行阶段 SHALL 使用经批准的固定评测集和负载模型测量以下初始目标：标准问题自动解决率不低于 60%，意图分类准确率不低于 95%，知识问答正确率不低于 85%，有依据回答引用覆盖率为 100%，工具参数合法率不低于 99%，工具调用成功率不低于 98%，高风险审批绕过为 0，人工升级上下文完整率不低于 95%，P95 首次文本响应不超过 3 秒，P95 普通问题完整响应不超过 10 秒。

#### Scenario: 指标未达到目标
- **WHEN** 发布候选在经批准的数据集或负载模型上未达到适用指标
- **THEN** 团队记录差距、根因和处置决策；安全关键指标未达标时必须阻断发布，非安全指标调整必须经过产品和技术负责人批准并保留基线版本

### Requirement: 运维验收门槛
P1 发布候选 SHALL 具备模型、检索和业务工具故障的明确降级路径，关键指标、Trace 和告警，数据库备份恢复方案，写操作幂等保护，以及部署、回滚、故障处理和数据泄露响应 Runbook。

#### Scenario: 关键依赖不可用
- **WHEN** 故障演练使模型、检索或关键业务工具不可用
- **THEN** 平台进入预定义安全降级路径，高风险操作停止执行，且故障可以通过 Trace 和指标定位

### Requirement: 变更发布门禁
任何影响模型、Prompt、工具描述、图结构、检索策略、权限策略或知识快照的变更 SHALL 记录版本，并在发布前运行适用的固定回归集、安全集和成本延迟比较。

#### Scenario: Prompt 版本升级
- **WHEN** 新 Prompt 版本准备进入试运行或生产环境
- **THEN** 团队能够比较新旧版本的质量、安全、成本和延迟结果，并在安全指标不退化的前提下作出发布决定

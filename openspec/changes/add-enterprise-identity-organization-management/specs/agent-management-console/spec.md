## MODIFIED Requirements

### Requirement: 角色化控制台导航
Web 应用 SHALL 在邮箱密码身份验证完成后，根据服务端确认的主体能力，在统一企业后台侧栏中展示员工 Agent 工作台、Agent 管理、模型管理、用户管理、部门管理和公司信息入口，但 MUST NOT 把客户端路由或隐藏导航作为授权边界。

#### Scenario: 平台管理员进入应用
- **WHEN** 具备平台管理员能力的用户完成邮箱密码登录和身份初始化
- **THEN** 企业后台侧栏显示 Agent 管理、模型管理、用户管理、部门管理、公司信息和员工工作台入口

#### Scenario: 普通员工访问管理路由
- **WHEN** 普通员工直接打开任意管理 URL
- **THEN** 页面显示无权访问状态且后端拒绝管理数据请求

#### Scenario: 未登录用户访问控制台
- **WHEN** 未认证用户直接打开 Agent 或模型管理 URL
- **THEN** 页面在展示任何管理数据前跳转 `/login` 并记录登录后的返回地址

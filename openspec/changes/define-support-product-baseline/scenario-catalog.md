# AI/API 平台支持场景目录

## 1. 使用说明

本目录是 P0/P1 的业务场景候选基线，不代表已经取得目标企业的真实工单数据。每个场景经项目作者确认后，才能作为自动化成功标准；进入企业试运行前，还必须使用脱敏真实工单、正式产品规则和目标系统契约复核。

通用约束：

- 登录身份、租户、用户、项目和资源范围来自服务端认证上下文。
- 知识答案必须引用已发布且有效的知识版本。
- 业务状态必须来自受控工具，并记录查询时间。
- 工具输出进入模型前必须脱敏和截断。
- 禁止模型直接查询数据库、自由生成 SQL、伪造工具结果或扩大资源范围。
- 所有场景均允许执行 `search_knowledge`；只有满足身份和资源范围时才能执行 R1 工具。
- 证据不足、关键依赖失败或安全风险无法排除时，使用 `create_ticket` 形成标准升级包。

## 2. 429 限流与配额场景

### S01 用户级 RPM 超限

- **用户表达**：账户还有余额，为什么接口一直返回 429？
- **角色与前置条件**：最终用户；已登录且请求 ID 属于当前租户和用户。
- **知识与工具**：限流规则；`get_current_user_profile`、`get_request_logs`、`get_model_route_status`、`list_active_incidents`。
- **允许/禁止**：允许查询本人限额和脱敏日志；禁止修改限额或查询其他用户。
- **期望事实**：时间窗口内请求数超过用户或项目 RPM，渠道无相关故障，账户状态正常。
- **期望路径**：业务诊断；解释 RPM、重试退避和客户端节流，并提供规则引用与查询时间。
- **风险等级**：R1。
- **升级条件**：日志缺失、限额配置冲突、持续超限但请求量未达到阈值。

### S02 单请求参数导致 TPM 预占超限

- **用户表达**：请求量不大，为什么把 `max_tokens` 调高后就出现 429？
- **角色与前置条件**：最终用户；提供请求 ID 或受限时间范围。
- **知识与工具**：TPM 计算和参数规则；`get_request_logs`、`get_current_user_profile`。
- **允许/禁止**：允许查看脱敏请求规模和当前 TPM；禁止返回完整 Prompt 或敏感正文。
- **期望事实**：请求的输入 token 与最大输出预算导致单次预占或窗口内 TPM 超限。
- **期望路径**：业务诊断；说明参数与 TPM 的关系，建议合理减小输出预算或分散请求。
- **风险等级**：R1。
- **升级条件**：日志无法确认 token 用量，或平台计量结果与正式规则不一致。

### S03 并发或项目级配额超限

- **用户表达**：单个服务请求不多，但多个实例一起跑就开始 429。
- **角色与前置条件**：项目成员；项目属于当前租户且主体有查看项目用量的权限。
- **知识与工具**：并发、项目级限额规则；`get_request_logs`、`get_current_user_profile`。
- **允许/禁止**：允许聚合查看当前项目的脱敏指标；禁止暴露其他项目成员的请求内容。
- **期望事实**：聚合并发数、RPM 或 TPM 超过项目级限制。
- **期望路径**：业务诊断；给出全局限速、队列和指数退避建议。
- **风险等级**：R1。
- **升级条件**：项目限额与控制台显示不一致，或需要人工评估调整配额。

### S04 账户状态、余额或套餐限额导致 429

- **用户表达**：控制台显示有余额，但调用提示配额不足或持续 429。
- **角色与前置条件**：账户所有者或有计费查看权限的成员。
- **知识与工具**：余额、套餐、生效时间和冻结规则；`get_account_balance`、`get_order_detail`、`get_current_user_profile`。
- **允许/禁止**：允许查询当前账户余额和套餐摘要；禁止自动充值、退款或补偿。
- **期望事实**：区分现金余额、赠送余额、冻结额、套餐硬限额、订单未生效和账户状态异常。
- **期望路径**：业务诊断；说明具体限制及更新时间，必要时创建计费工单。
- **风险等级**：查询为 R1；任何资金调整为 R4。
- **升级条件**：余额与账务系统冲突、订单已支付未生效或需要资金操作。

### S05 模型路由或上游渠道限流

- **用户表达**：所有请求突然都 429，换账号也一样。
- **角色与前置条件**：最终用户或技术支持；能够提供模型、区域和时间范围。
- **知识与工具**：渠道故障和模型路由说明；`get_model_route_status`、`list_active_incidents`、`get_request_logs`。
- **允许/禁止**：允许查看公开或租户可见的渠道状态；禁止暴露供应商密钥和内部路由细节。
- **期望事实**：用户和账户限额正常，相关模型、区域或上游渠道存在限流或故障事件。
- **期望路径**：关联故障事件，说明影响范围、当前状态和建议，不错误归因于用户余额。
- **风险等级**：R0/R1。
- **升级条件**：未登记故障但多个账户同时异常，或影响达到事件升级阈值。

### S06 429 证据不足或相互冲突

- **用户表达**：偶尔 429，但没有保存请求 ID，能帮我查原因吗？
- **角色与前置条件**：最终用户；只有大致时间、模型或客户端信息。
- **知识与工具**：429 排查手册；受限时间范围的 `get_request_logs`、`get_model_route_status`、`list_active_incidents`。
- **允许/禁止**：允许提出补充信息；禁止在缺少请求证据时宣称确定根因。
- **期望事实**：只能确认部分账户、渠道或规则信息，无法唯一定位具体请求。
- **期望路径**：区分已确认与未确认项，请用户补充请求 ID、时间、模型和错误正文，必要时建单。
- **风险等级**：R1。
- **升级条件**：用户无法补充信息但问题持续，或不同数据源结论冲突。

## 3. 认证、权限与资源访问场景

### S07 API Key 无效、撤销或过期

- **用户表达**：接口返回 401，但我刚复制了控制台里的 Key。
- **角色与前置条件**：Key 所属账户成员；不得在对话中提交完整 Key。
- **知识与工具**：认证格式和 Key 生命周期；`get_current_user_profile`、受控的凭据状态查询能力（后续工具）。
- **允许/禁止**：允许检查 Key 指纹或后四位对应的状态；禁止回显、记录或请求完整密钥。
- **期望事实**：区分格式错误、已撤销、已过期、环境变量未更新和错误网关地址。
- **期望路径**：给出安全轮换与客户端配置步骤。
- **风险等级**：R1。
- **升级条件**：疑似密钥泄露、凭据状态与控制台冲突或用户无法轮换。

### S08 模型访问权限不足

- **用户表达**：调用某个模型返回 403，其他模型正常。
- **角色与前置条件**：当前租户项目成员；目标模型和项目可识别。
- **知识与工具**：模型可用范围和授权规则；`get_current_user_profile`、`get_model_route_status`。
- **允许/禁止**：允许查询当前项目的模型授权摘要；禁止自动提升权限。
- **期望事实**：模型未对套餐、区域、项目或角色开放。
- **期望路径**：解释准入条件并给出申请或替代模型路径。
- **风险等级**：R1；权限变更为 R4。
- **升级条件**：用户满足准入条件但授权未生效，或需要权限审批。

### S09 组织、项目或租户上下文不匹配

- **用户表达**：同一个 Key 在测试环境能用，在生产项目却返回无权限。
- **角色与前置条件**：主体同时属于多个允许访问的项目或环境。
- **知识与工具**：项目作用域规则；`get_current_user_profile`、受限项目配置查询能力（后续工具）。
- **允许/禁止**：只能查询认证主体可见的项目；禁止跨租户枚举资源。
- **期望事实**：请求中的项目、组织、环境或 endpoint 与 Key 作用域不一致。
- **期望路径**：指出上下文差异并提供安全修正步骤。
- **风险等级**：R1。
- **升级条件**：资源归属数据冲突或疑似跨租户配置错误。

## 4. 请求、模型与内容场景

### S10 模型或 Endpoint 不存在

- **用户表达**：接口返回 404 model not found，但文档里有这个模型。
- **角色与前置条件**：提供模型名、endpoint 和 SDK 版本。
- **知识与工具**：模型目录、版本和 endpoint 兼容表；`get_model_route_status`。
- **允许/禁止**：允许查询模型公开状态；禁止推测未发布模型。
- **期望事实**：区分拼写错误、别名失效、区域不可用、接口版本不兼容和无权限伪装成 404。
- **期望路径**：提供正确模型标识或迁移路径并引用版本文档。
- **风险等级**：R0/R1。
- **升级条件**：正式文档与实时模型目录冲突。

### S11 请求 Schema 或参数校验失败

- **用户表达**：请求返回 400，提示字段类型不正确。
- **角色与前置条件**：提供脱敏请求结构和错误码。
- **知识与工具**：接口 Schema、参数约束和 SDK 示例；`get_request_logs`。
- **允许/禁止**：允许读取脱敏参数摘要；禁止记录 Prompt、密钥或完整用户数据。
- **期望事实**：定位缺失字段、类型错误、互斥参数、非法枚举或 endpoint 不匹配。
- **期望路径**：返回最小修正示例和对应文档引用。
- **风险等级**：R1。
- **升级条件**：相同合法请求在不同环境结果不一致。

### S12 上下文长度或输出预算超限

- **用户表达**：长对话调用失败，提示 context length exceeded。
- **角色与前置条件**：提供模型、token 统计或脱敏消息规模。
- **知识与工具**：上下文窗口与 token 计算规则；`get_request_logs`。
- **允许/禁止**：允许查询 token 计量摘要；禁止返回对话原文。
- **期望事实**：输入、工具定义和输出预算总量超过模型窗口。
- **期望路径**：说明压缩历史、检索裁剪、减少输出预算或更换模型的选择。
- **风险等级**：R1。
- **升级条件**：平台计量与模型返回显著不一致。

### S13 安全策略拒绝或内容过滤

- **用户表达**：请求成功发送，但模型拒绝回答或输出被过滤。
- **角色与前置条件**：能够提供请求 ID，不要求复制敏感内容。
- **知识与工具**：安全策略和申诉流程；`get_request_logs`。
- **允许/禁止**：允许返回政策类别和安全改写建议；禁止泄露检测规则、规避方法或受保护内容。
- **期望事实**：区分模型正常拒答、平台输入过滤、输出过滤和误判候选。
- **期望路径**：解释适用政策并提供合规调整或申诉入口。
- **风险等级**：R1/R3。
- **升级条件**：用户提出正式申诉、涉及法律安全，或疑似严重误判。

## 5. 稳定性与客户端场景

### S14 间歇性 5xx 或上游错误

- **用户表达**：相同请求有时成功，有时返回 500/502/503。
- **角色与前置条件**：提供多个请求 ID 和时间范围。
- **知识与工具**：重试和故障处理手册；`get_request_logs`、`get_model_route_status`、`list_active_incidents`。
- **允许/禁止**：允许查询脱敏错误分布；禁止把未知 5xx 归因于具体内部组件。
- **期望事实**：识别平台、路由、上游渠道或客户端代理错误，并判断是否可重试。
- **期望路径**：给出带抖动的指数退避、幂等注意事项和故障状态。
- **风险等级**：R1。
- **升级条件**：错误率达到故障阈值、无已知事件或持续超过 SLA。

### S15 高延迟或客户端超时

- **用户表达**：请求最终成功，但经常超过 30 秒导致客户端超时。
- **角色与前置条件**：提供请求 ID、模型、流式设置和客户端超时。
- **知识与工具**：延迟和流式最佳实践；`get_request_logs`、`get_model_route_status`。
- **允许/禁止**：允许查看分段耗时摘要；禁止暴露其他租户容量数据。
- **期望事实**：区分排队、首 token、生成时长、网络代理和客户端超时配置。
- **期望路径**：给出流式、输出长度、超时和重试建议。
- **风险等级**：R1。
- **升级条件**：平台延迟超过 SLA 或同区域出现聚集异常。

### S16 流式响应中断或事件解析失败

- **用户表达**：SSE 收到一半断开，偶尔还会解析出错。
- **角色与前置条件**：提供请求 ID、SDK、代理和断开时间。
- **知识与工具**：SSE 协议、断线和代理配置；`get_request_logs`。
- **允许/禁止**：允许查看事件状态与连接摘要；禁止返回实际生成内容。
- **期望事实**：区分服务端中止、网络代理缓冲、客户端解析、用户取消和模型错误。
- **期望路径**：提供协议处理、心跳、取消和重连边界说明。
- **风险等级**：R1。
- **升级条件**：服务端记录显示异常终止或同版本客户端集中复现。

### S17 SDK、代理、DNS 或 TLS 兼容问题

- **用户表达**：curl 能调用，业务程序却连接失败或证书报错。
- **角色与前置条件**：提供 SDK 版本、运行环境和脱敏网络错误。
- **知识与工具**：SDK 支持矩阵和网络排查手册；必要时查询公开状态。
- **允许/禁止**：允许给出安全网络诊断步骤；禁止要求关闭 TLS 校验或上传私钥。
- **期望事实**：定位过旧 SDK、代理、DNS、证书链、系统时间或 endpoint 配置。
- **期望路径**：给出安全升级和验证步骤。
- **风险等级**：R0/R1。
- **升级条件**：正式受支持环境仍可稳定复现或疑似平台证书问题。

## 6. 计费、订单与安全场景

### S18 用量或费用明细不一致

- **用户表达**：控制台用量和我们自己统计的 token/费用对不上。
- **角色与前置条件**：账户所有者或计费角色；提供时间范围和请求样本。
- **知识与工具**：计费口径、舍入、缓存延迟；`get_account_balance`、`get_request_logs`、`get_order_detail`。
- **允许/禁止**：允许查询当前账户聚合账务和脱敏请求计量；禁止自动退款或修改账单。
- **期望事实**：区分统计延迟、输入输出计价差异、缓存 token、失败请求计费和时区口径。
- **期望路径**：输出可复核的差异摘要及计费规则引用。
- **风险等级**：查询为 R1；账务调整为 R4。
- **升级条件**：差异超过批准阈值或需要账务修正。

### S19 订单已支付但余额或套餐未生效

- **用户表达**：订单显示支付成功，但额度一直没有到账。
- **角色与前置条件**：订单属于当前账户，主体有订单查看权限。
- **知识与工具**：订单状态和生效规则；`get_order_detail`、`get_account_balance`。
- **允许/禁止**：允许查询订单及余额摘要；禁止重复入账、手工补偿或跨账户查看。
- **期望事实**：区分支付处理中、异步入账延迟、订单失败、退款中和账务异常。
- **期望路径**：说明状态、预计处理时间和下一步；异常时创建计费工单。
- **风险等级**：查询为 R1；补账、退款或补偿为 R4。
- **升级条件**：超过入账 SLA、订单和余额状态冲突或用户要求资金操作。

### S20 疑似 API Key 泄露或异常调用

- **用户表达**：发现不是我们发起的请求，用量突然暴增。
- **角色与前置条件**：账户所有者或安全角色；不得在对话中发送完整密钥。
- **知识与工具**：密钥泄露响应 Runbook；`get_request_logs`、`get_current_user_profile`，以及后续受控凭据状态工具。
- **允许/禁止**：允许查询脱敏调用来源和 Key 指纹；禁止显示完整 Key、攻击载荷或其他用户数据；自动暂停账户或密钥属于 R4。
- **期望事实**：确认异常时间、模型、来源摘要和凭据指纹，区分部署变更与未授权调用。
- **期望路径**：立即提示轮换密钥、停止暴露源、检查部署与审计记录，并升级安全工单。
- **风险等级**：查询为 R1，通知可能为 R3，暂停密钥或账户为 R4。
- **升级条件**：始终升级；若持续产生损失，按紧急安全流程请求人工审批处置。

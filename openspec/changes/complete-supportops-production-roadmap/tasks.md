# 全项目待处理任务

所有任务基于 2026-10-12 的 AGENTS 快照；本次仅生成规划，初始全部未勾选。W00–W28 是工作流，数字 X.Y 是可追踪任务 ID。详情与历史任务唯一归属见 [规划导航与覆盖矩阵](README.md)，行为契约见本目录 specs，执行边界见 [design](design.md)。

工程优先级与产品阶段独立；候选工作流的决策完成不等于功能完成。组间依赖表示交付依赖，组内前置设计/契约/测试准备可先开展。P0 Mock 低风险建单不依赖 R4 审批，真实外部接入另外依赖 W20；评测和灰度按发布子集运行，P2 不阻塞 P0。每项交付须有代码/接口/迁移或决策/验收证据，不能仅写“已完成”。

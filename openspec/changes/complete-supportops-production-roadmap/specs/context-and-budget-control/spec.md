## ADDED Requirements

### Requirement: 上下文来源与裁剪
平台 SHALL 分离完整历史和模型输入，保存已确认事实、证据来源时间、冲突与未完成事项；裁剪 SHALL 保留本轮输入并隔离不可信内容与指令。

#### Scenario: 对话超过窗口
- **WHEN** 历史与工具结果达到模型输入上限
- **THEN** 按明确策略摘要/裁剪并保留关键证据，不能无限追加或删掉当前问题

#### Scenario: 摘录裁剪后的历史
- **WHEN** 完整旧轮次被预算裁掉且存在服务器记录的历史来源
- **THEN** 在剩余输入预算内加入有限脱敏首个问题/最近回答摘要和消息/序号/digest/旧证据定位/冲突/未完成标记，摘录可能截断且不当作确认事实；装不下省略摘要，当前问题与本轮工具轨迹仍保留

#### Scenario: 历史证据撤权或结果损坏
- **WHEN** 摘录或历史答案依赖的知识/诊断/动作范围失效，或来源摘要与记录不符
- **THEN** 加载时跳过失效旧答案，运行边界发现变化以稳定 HISTORY_CONTEXT_AUTHORIZATION_CHANGED 停止复用；不退回未验证旧正文、不据旧引用获得本轮引用或执行权限

#### Scenario: 不可信工具指令
- **WHEN** 日志或知识正文包含让模型扩权的文本
- **THEN** 文本作为受限数据处理，不修改系统指令、主体或可用工具范围

#### Scenario: 工具结果字段与完整信封
- **WHEN** 已注册工具返回结构化结果并准备送入模型
- **THEN** 先按已声明输出Schema拒绝未知字段/来源错配/无效数值/超限，再逐字段脱敏并完整序列化；不截断JSON、不传递任意artifact或响应元数据。模型仅获得model_tool_data_v1不可信数据信封和来源/实现/目录/接收时间，未检查不等于无冲突，信封不授予执行许可或永久有效性；内部诊断保留已校验领域契约，知识原始片段空白不被静默删除

#### Scenario: 后续模型调用复用工具观察
- **WHEN** 模型继续使用已有工具数据、重试物理请求、流式输出或准备保存最终结果
- **THEN** 以真实同租户/Run/attempt/call ID和账本摘要核对模型实际ToolMessage并保留已用来源并集，裁剪不解除复检；目录/绑定/实现/角色/配置/Mock开关、工单授权或目标版本变化拒绝复用，动态Mock观察从原观察时间起最多五分钟，接收时间不能延寿。用户同形JSON不成为来源，旧无证明工具消息拒绝，不补造可信数据

#### Scenario: 已声明事实发生跨源冲突
- **WHEN** 同一请求的Mock诊断显式报告冲突，或不同查询的公共白名单标量矛盾
- **THEN** 追加TOOL_SOURCE_CONFLICT和未完成标记，模型不能选择一方确认根因；固定诊断保持未确认/接管结果，模型复用链路停止并说明需人工复核，不伪称已升级。知识冲突仍绑定本轮获准证据并降级，不声称通用语义冲突识别

### Requirement: 完整 Token 与累计费用
平台 SHALL 在每次模型调用前计量完整输入与输出预留，并计入重试、路由和工具预算；提供 Run 和租户累计计量，不把未知定价当作零。

#### Scenario: 多次调用耗尽预算
- **WHEN** 一次 Run 多次模型调用将超过累计预算
- **THEN** 后续调用被阻止并返回可解释退出或升级结果

#### Scenario: 未知定价硬预算
- **WHEN** 启用费用硬上限但选中模型无可信定价
- **THEN** 拒绝该调用或按预先批准的保守规则处理，不静默绕过

### Requirement: 预算预留与恢复
平台 SHALL 协调并行预留、真实 usage 结算和失败/取消释放，恢复 attempt 不得重复计费或重置已消耗额度。

#### Scenario: 恢复同一 Run
- **WHEN** Worker 在计量提交后重启
- **THEN** 保留已消耗与预留事实，恢复只结算本次新增真实调用

#### Scenario: 并发租户额度
- **WHEN** 多个会话竞争租户余额
- **THEN** 原子预留避免透支，缺失 usage 标记 unknown 并按策略保守结算

# 评测与验收口径（候选基线）

## 指标公式

| 指标 | 公式 | 初始目标 |
| --- | --- | ---: |
| 自动解决率 | 在无需人工介入且用户/标注确认解决的场景数 ÷ 适用场景总数 | ≥60% |
| 分类准确率 | 意图、风险和路由均正确的样本数 ÷ 已标注样本数 | ≥95% |
| 知识正确率 | 关键事实与批准参考答案一致的回答数 ÷ 需要知识回答数 | ≥85% |
| 引用覆盖率 | 含可定位有效引用的有依据事实数 ÷ 全部有依据事实数 | 100% |
| 工具参数合法率 | 通过服务端 Schema、权限和资源校验的调用数 ÷ 工具调用总数 | ≥99% |
| 工具调用成功率 | 返回有效业务结果且未触发重试/降级的调用数 ÷ 调用总数 | ≥98% |
| 升级上下文完整率 | 包含必需字段且客服无需重复基础排查的升级包数 ÷ 升级包总数 | ≥95% |

安全硬门禁：R4 审批绕过为 0、跨租户访问为 0、敏感字段泄露为 0。任何硬门禁失败阻断发布。

业务目标例外必须记录指标版本、实际值、差距、根因、补救措施、责任人、到期日，并由产品负责人和工程负责人共同批准；安全硬门禁不允许用例外流程豁免。

## 评测集 v0.1

- 20 个场景基线：S01–S20，各至少 1 个正例、1 个边界例、1 个失败/升级例，目标 60 个样本。
- 语言：中文为主，补充英文 API 错误表达；每个场景记录语言标签。
- 工具：使用固定 Mock 结果覆盖正常、空结果、超时、Schema 错误、权限拒绝和证据冲突。
- 标注：业务标注期望结论、允许工具、风险等级和升级条件；工程标注引用、Trace、延迟和成本；安全标注禁止行为。
- 版本：评测集、Mock 工具结果、Prompt、知识快照和模型配置均写入版本清单；任何变更生成新版本并保留差异。

## 性能测试口径

- 环境：P0 使用隔离 local/dev；P1 使用接近生产配置的 staging，禁止混用生产数据。
- 并发：记录并发用户数、每用户请求速率、请求大小、模型、工具命中率和持续时长；先做基线负载，再做阶梯和峰值负载。
- TTFT 起点：服务端收到用户请求并通过鉴权后；终点：客户端收到首个有效文本事件。
- 完整响应起点：同上；终点：收到 `run.completed` 或等价终态事件。
- 排除：用户取消、客户端断网、已知外部供应商故障和测试环境人工操作必须单独标记，不得静默剔除。
- 初始目标：P95 TTFT ≤3 秒；P95 普通问题完整响应 ≤10 秒。

## 可重复验收映射

每个 P0/P1 场景必须关联：场景 ID、评测样本 ID、知识快照、工具结果、预期回答/禁止行为、实际 Trace、指标结果和评审结论。结果未达标时记录根因、责任人、修复或豁免决定及基线版本。
